Chrono Sport

Application mobile de gestion d’événements sportifs développée pendant le stage chez Mega Pixel.

FlutterLaravelMySQLFirebase Cloud Messaging

Contexte & objectifs

Le travail porte sur l’application mobile, l’intégration des API, la gestion des données et les notifications destinées à améliorer le suivi des participants.

Fonctionnalités et travaux

  • Développement mobile avec Flutter.
  • Conception et intégration d’API REST avec Laravel.
  • Notifications avec Firebase Cloud Messaging.
  • Gestion des données dans MySQL.
  • Amélioration de l’expérience utilisateur mobile.

Technologies

Flutter · Laravel · MySQL · Firebase Cloud Messaging
