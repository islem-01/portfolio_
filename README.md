# Portfolio Islem Zouari

Portfolio statique HTML/CSS/JavaScript, conçu pour un hébergement statique (GitHub Pages compatible).

## Lancer en local

- Ouvrir `index.html` dans un navigateur, ou lancer un serveur statique depuis ce dossier, par exemple `python -m http.server 8000`.
- Accéder ensuite à `http://localhost:8000`.

## Déploiement GitHub Pages

Publier le contenu de ce dossier à la racine de la branche/dossier configuré dans GitHub Pages. Le site n'utilise pas de backend. Les polices web chargées via Google Fonts nécessitent une connexion Internet ; des polices système restent disponibles en fallback.

## Contenu fourni

- Pages principales : Accueil, Parcours, Compétences, Expériences, Projets, Contact.
- Pages de détail : SmartCampus AI, Smart Exam Monitoring System, SmartEvent360, Chrono Sport, gestion scolaire, rappel de médicaments, WordPress événements, Bibliothèque, Pharmacy et Badge Scanner.
- CV PDF, photo, logo IIT et icônes de contact fournies.
- Vidéos de démonstration et captures de l'application de rappel de médicaments issues de l'archive média fournie.
